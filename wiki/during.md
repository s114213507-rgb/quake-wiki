# 震中保命：趴下、掩護、穩住
> 搖晃時不要往外跑，就地「趴下、掩護、穩住」，最重要是保護頭和脖子。
來源：[S02] [S03] [S06]
相關：[[warning]] [[after]] [[myths]]

## 三步驟
- **趴下**：降低身體，避免被搖倒 [S02]。
- **掩護**：躲到堅固的桌子下，或蹲在主要柱子旁，保護頭部 [S02]。
- **穩住**：抓住桌腳，桌子移動就跟著移動，直到地震結束 [S02] [S06]。
- 不要慌亂逃出戶外，先保護頭頸 [S06]。

## 不同地方怎麼做
| 地方 | 怎麼做 |
|---|---|
| 床上 | 待在床上，轉身趴下，用枕頭保護頭頸 [S06] |
| 廚房 | 順手關爐火，再躲到桌子下 [S02] |
| 廁所 | 身體壓低，拿東西護頭頸 [S06] |
| 公共場所 | 就地避難，搖完聽服務人員引導，「不推、不語、不跑」[S02] |
| 戶外 | 蹲低，用隨身物品護頭頸，小心招牌、電線、碎玻璃，不要跑進室內 [S02] [S06] |
| 開車 | 不要急煞，慢慢減速、開警示燈、靠路邊停 [S02] [S06] |
| 海邊、河口 | 儘快往高處避難，防海嘯 [S02] |

## 要避開的東西
- 衣櫃、書櫃、冰箱、電視等會倒的家具電器 [S02]。
- 吊燈、吊扇、玻璃 [S02]。
